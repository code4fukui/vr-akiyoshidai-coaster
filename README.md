# vr-akiyoshidai-coaster

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

A virtual reality roller coaster experience featuring a 3D model of the Akiyoshidai stone monument from Yamaguchi Prefecture, Japan. Built with Three.js and WebXR.

- **[Live Demo: VR秋吉台コースターβ](https://code4fukui.github.io/vr-akiyoshidai-coaster/)**

This project is forked from [VR東尋坊コースター](https://github.com/code4fukui/vr-tojinbo/).

## Key Features

- **Immersive VR Experience:** Full WebXR support for VR headsets.
- **Procedural Track:** The roller coaster path is generated by a mathematical curve, not a pre-built model.
- **Dynamic Audio:** A custom `AudioWorkletProcessor` creates a wind effect where the pitch and volume change in real-time based on the coaster's velocity.
- **3D Scenery:** Integrates a 3D model of the Akiyoshidai stone monument as the central feature.

## Usage

To run this project, you need a modern browser with WebXR support.

1.  Clone the repository.
2.  Run a local web server from the project's root directory. (Opening `index.html` directly from the filesystem will not work due to browser security policies for loading assets).
3.  Open the local server's URL in your browser.
4.  Click the "Enter VR" button to start in a VR headset. For desktop viewing, click anywhere on the screen to enable audio.

## Open Data & Technology

- **3D Model:** The Akiyoshidai stone monument (`akiyoshidai-board.glb`) is from [秋吉台石板 from XRモニュメント](https://code4fukui.github.io/xrmonument/).
- **Track Generation:** The coaster's path and track geometry are created procedurally using `RollerCoasterGeometry` and a custom `Curve` class in `Coaster.js`.
- **Audio Processing:** The wind sound is generated by modulating a `wind.wav` sample using a custom `WindProcessor` AudioWorklet, which is controlled by the coaster's simulated speed.
