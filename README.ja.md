# vr-akiyoshidai-coaster

山口県の秋吉台石板の3Dモデルをフィーチャーした、バーチャルリアリティ（VR）ジェットコースター体験です。Three.jsとWebXRを使用して構築されています。

- **[ライブデモ: VR秋吉台コースターβ](https://code4fukui.github.io/vr-akiyoshidai-coaster/)**

このプロジェクトは [VR東尋坊コースター](https://github.com/code4fukui/vr-tojinbo/) からフォークされています。

## 主な特徴

- **没入型のVR体験:** VRヘッドセット向けにWebXRを完全サポート。
- **プロシージャルな軌道生成:** ジェットコースターの軌道は、事前に作成されたモデルではなく、数式（数学的曲線）によって生成されます。
- **動的なオーディオ:** カスタムの `AudioWorkletProcessor` により、コースターの速度に応じて音のピッチと音量がリアルタイムで変化する風の効果を実現しています。
- **3Dの景観:** 秋吉台石板の3Dモデルをメインの景観として統合しています。

## 使い方

このプロジェクトを実行するには、WebXRをサポートするモダンブラウザが必要です。

1. リポジトリをクローンします。
2. プロジェクトのルートディレクトリからローカルのWebサーバーを起動します。（アセット読み込みに関するブラウザのセキュリティポリシーにより、ファイルシステムから直接 `index.html` を開いても動作しません）。
3. ブラウザでローカルサーバーのURLを開きます。
4. VRヘッドセットで開始するには「Enter VR」ボタンをクリックします。デスクトップで閲覧する場合は、画面の任意の場所をクリックしてオーディオを有効にしてください。

## オープンデータと技術

- **3Dモデル:** 秋吉台石板（`akiyoshidai-board.glb`）は [秋吉台石板 from XRモニュメント](https://code4fukui.github.io/xrmonument/) のものを使用しています。
- **軌道生成:** ジェットコースターの経路と軌道のジオメトリは、`RollerCoasterGeometry` と `Coaster.js` 内のカスタム `Curve` クラスを使用してプロシージャルに生成されています。
- **オーディオ処理:** 風の音は、カスタムの `WindProcessor` AudioWorklet を使用して `wind.wav` のサンプルを変調することで生成され、コースターのシミュレーション速度によって制御されます。
